## 📝 Sobre o Projeto

A **GBXP (Game Barretos Experience)** é um site fictício criado para representar um evento municipal da cidade de Barretos voltado ao universo dos games, com foco principal nos jogos da saga **Star Wars**.

Este projeto foi desenvolvido como parte da **avaliação do 2º semestre do curso técnico em Análise e Desenvolvimento de Sistemas do SENAC - 2023**.

### 🔍 Funcionalidades:
- **Landing Page**: Apresentação do evento e do projeto.
- **Formulário de Inscrição**: Cadastro de participantes para o evento fictício.
- **Loja Virtual**: Página com produtos exclusivos do evento disponíveis para aquisição.
